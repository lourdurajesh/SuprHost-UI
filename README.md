# SuprHost-UI

Direct Booking product: the public, SSR booking websites (and later Website Studio and mobile).

The PMS lives in `HostMate-UI` (host console) and `HostMate-Backend` (the one PMS + public API).
SuprHost-UI never touches the PMS database; it talks only to the backend's public API.

- `docs/ROADMAP.md` — versioned releases
- `docs/ARCHITECTURE.md` — architecture, security, spam, performance and plugin standards
